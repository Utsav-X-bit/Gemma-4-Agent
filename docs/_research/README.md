# Research Notes (Not the Playbook)

This directory contains the raw fact sheets and audit reports used to build the playbook. They are **not** the final guide and may contain contradictions that were resolved later.

- `harness-facts.md` — line-referenced facts from `harness_readme_raw.md`.
- `notebook-facts.md` — line-referenced facts from `getting_started_notebook.txt`.
- `reviews/source-audit.md` — claim/citation audit of the first draft.
- `reviews/harness-audit.md` — technical consistency audit of `01`–`04`.
- `reviews/strategy-audit.md` — end-to-end plan audit.
- `reviews/runbook-exec.md` — command/path executability audit.
- `reviews/final-consistency.md` — post-fix consistency review.

The authoritative guide is:

- `README.md` — master plan.
- `docs/00-competition.md` through `docs/07-paper-and-small-model.md` — deep dives.
- `docs/SOURCES.md` — claim ledger with URLs and line references.

If a raw note conflicts with the final docs, the final docs and `SOURCES.md` win. If a final doc conflicts with the live competition page, the live page wins; re-check before submitting.
